# The Driver of God: The Anatomy of Self-Will

> *“The question is not ‘Who is God?’ It is: ‘Who is driving my understanding of God?’”*

An interactive philosophical inquiry, psychological diagnostic, and cinematic audiovisual experience exploring the ancient progression of **Pride**, **Self-Will**, **Self-Centeredness**, and **Playing God**, counterbalanced by the contemplative practice of **Kenosis** (sacred surrender).

---

## ✨ Features & Architecture

* **The Astrolabe of the Psyche**: An interactive mechanical compass examining the 4 cognitive drivers with drag mechanics, pointer capture, and responsive sound cues.
* **The Diagnostic Inquest**: An 8-crucible psychological self-inventory calculating your Self-Will index, primary driver, and unconscious ignition node, with multi-session historical trend tracking stored locally.
* **Inner Light 9:16 Cinematic Studio**: Vertical film studio exploring the Anahata Heart Chakra through Hermetic axioms (*“As Above, So Below”*), real-time Web Audio Solfeggio frequency synthesizer (528 Hz, 432 Hz, 741 Hz), and production script export.
* **The Cosmic Orrery**: Comparative celestial simulation demonstrating the cognitive shift between the Ptolemaic (Geocentric / Ego-centered) and Copernican (Heliocentric / Surrendered) spiritual mindsets.
* **The Katha Upanishad Chariot**: An interactive visual treatise on the allegory of the senses, reins, intellect (*Buddhi*), and true witness (*Ātman*).
* **The Kenosis Chamber**: A 4-stage guided meditative sanctuary with a 4-7-8 breathing geometry mandala and 108 Hz acoustic harmonic drone.

## 🔒 Security & Privacy Guarantees

When shared live via GitHub Pages or a public link:

1. **Tamper-Proof Code**: The site is compiled into static assets. Visitors cannot modify the live site or execute unauthorized code.
2. **100% Private Client-Side Storage**: Inquest scores and progression history are saved exclusively in each visitor’s browser `localStorage`. Under the browser’s Same-Origin Policy, no visitor can ever view or tamper with another visitor's data.
3. **Zero Secrets or API Keys**: The app runs purely on client-side Web Audio API, SVG graphics, and math algorithms. No private tokens or database credentials exist in the client bundle.

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/<YOUR-USERNAME>/the-driver-of-god.git

# Navigate to project directory
cd the-driver-of-god

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` to explore the experience.

## 🌐 Deploy to GitHub Pages (Automated)

This repository includes a pre-configured GitHub Actions workflow in `.github/workflows/deploy.yml`:

1. Create a repository on GitHub (e.g. `the-driver-of-god`).
2. Push this codebase to the `main` branch.
3. On GitHub, navigate to **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **GitHub Actions**.
5. Your application will automatically build and publish to `https://<YOUR-USERNAME>.github.io/the-driver-of-god/`!
